# HKL-PoMS v2

Postgraduate Monitoring System for Master's (Sarjana) students, Emergency & Trauma Department, Hospital Kuala Lumpur.

Live site: https://avedhkl.github.io/hkl-poms-v2/

This repository holds only the web front end (`index.html`). All data is stored in a private Google Sheet and served through a Google Apps Script web app; no personal data is kept here.
